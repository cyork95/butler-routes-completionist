# Butler Routes - Completionist

Completionist (all-quests) routes for [Polestar](https://polestar.guide), the guide addon for **WoW Forever**: every quest in a zone, in a sensible order. The opposite of speed-leveling routes — follow one of these and nothing gets left behind.

Pack id `butler-routes-completionist`. Title "Butler Routes - Completionist". Author Butler Muse. License CC-BY-4.0.

Status: **in development (pack v0.139.0), not published yet**. The first release (v1.0.0) is planned when the starting-zone set is complete.

Each quest guide takes every quest on the zone's tracker list exactly once: 145 accepts / 145 turn-ins for Zephras Isle, 83 / 83 for Elwynn Forest, 43 / 43 for Westfall, 105 / 105 for Dun Morogh, 41 / 41 for Loch Modan, 96 / 96 for Teldrassil, 74 / 74 for Darkshore, 189 / 189 for Stormwind City, and 188 accepts / 186 turn-ins for Ironforge (two contracted quests have no turn-in in the data and ship accept-only with a note). Class quests for other classes are included and gated with `only`, so they never show for a character they are not for.

The two pilot companions run in their own Polestar tab beside the Zephras core route: the rares guide sweeps all 8 confirmed rares plus the fixed Dented Chest placements (every goal optional, so a rare that is not up never holds the route), and the recipes guide collects the 12 vendor-sold recipe sources on the isle, gated by profession.

The two Elwynn companions run the same way beside the Elwynn core route: the rares guide sweeps 24 confirmed rares plus the fixed world containers (Battered and Solid Chests, stashboxes, Buried Treasure), and the recipes guide collects the 4 vendor-sold recipe sources in Goldshire and Eastvale, gated by profession.

The two Westfall companions run the same way beside the Westfall core route: the rares guide sweeps 14 confirmed rares plus the fixed world containers (Battered and Duskwood Chests, clams, crates, Mech Arms), and the recipes guide collects the 9 vendor-sold recipe sources at the coast, Moonbrook and Sentinel Hill plus one mob-dropped schematic, gated by profession.

The two Dun Morogh companions run the same way beside the Dun Morogh core route: the rares guide sweeps 11 confirmed rares plus the fixed world containers (Battered Chests, caches, footlockers, a strongbox), and the recipes guide collects the 2 vendor-sold recipe sources plus one mob-dropped schematic, gated by profession.

The two Loch Modan companions run the same way beside the Loch Modan core route: the rares guide sweeps 10 confirmed rares plus the Carved Figurine (a level-32 chain starter, banked for later) and the fixed Battered Chest placements, and the recipes guide collects the 10 vendor-sold recipe sources in Thelsamar and Farstrider Lodge, gated by profession.

The two Darkshore companions run the same way beside the Darkshore core route: the rares guide sweeps 18 confirmed rares (including the Ghost Saber, summoned at the Mathystra cat figurines, and the Baron Marinous hunt, which feeds the contracted core quest) plus the fixed world containers (Battered Chests, Giant Clams, Waterlogged Footlockers and six one-off lockboxes), and the recipes guide collects the 13 vendor-sold recipe sources in Auberdine, from Heldan Galesong and from Bale, gated by profession.

The two Teldrassil companions run the same way beside the Teldrassil core route: the rares guide sweeps 19 confirmed rares (including the Moss-twined Heart hunt on Blackmoss, which feeds the contracted core quest) plus the fixed world containers (Battered Chests, Buried Treasure, Lunar Chest, harpy chests, Gnarlpine caches, Velinde's Locker), and the recipes guide collects the 6 vendor-sold Cooking recipe sources in Dolanaar and Rut'theran, gated by profession.

The two Hillsbrad companions run the same way beside the Hillsbrad core route: the rares guide sweeps 7 confirmed rares plus the fixed world containers (Hidden Strongboxes, Solid and Alliance Chests, melon-juice barrels, food crates, Syndicate footlockers), and the recipes guide collects the 25 vendor-sold recipe sources from Southshore to Dun Garok plus 4 mob-dropped exclusives, gated by profession.
The two Redridge companions run the same way beside the Redridge core route: the rares guide sweeps 8 confirmed rares (none with loot in the data - pure kills) plus the fixed world containers (Battered and Solid Chests, food and milk crates, Waterlogged Footlockers, Lucius's Lockbox and the Lakeshire practice lockboxes), and the recipes guide collects the 321 vendor-sold recipe sources at Lakeshire and the southwestern trade-skill camp plus 4 mob-dropped exclusives, gated by profession.
The two Arathi companions run the same way beside the Arathi core route: the rares guide sweeps 9 confirmed rares (none with loot in the data - pure kills) plus the fixed world containers (Solid and Alliance Chests, sweet-nectar barrels, food crates, Illari's Loot Cache), and the recipes guide collects the 15 vendor-sold recipe sources from Refuge Pointe to the keep plus 8 mob-dropped exclusives, gated by profession.

The two Ashenvale companions run the same way beside the Ashenvale core route: the rares guide sweeps 12 confirmed in-band rares (none with loot in the data - pure kills, including the Horde-aligned Apothecary Falthis) plus 121 fixed world-container placements with no unique treasure, and the recipes guide collects the 9 vendor-sold recipe sources plus 10 single-mob exclusive drops, gated by profession.

The first city guide covers Stormwind City: 189 quests that accept inside the city at every level, grouped by district with the chains kept together, plus expedition steps that run the out-of-city objectives at their data-placed locations.

The second city guide covers Ironforge: 188 quests that accept inside the city at every level, district-grouped with the chains kept together, plus accept-based expedition steps to more than twenty destination zones.

The fourth city guide covers Orgrimmar: 173 quests that accept inside the city across levels 1-60, grouped by district with the chains kept together, plus expedition steps that run the out-of-city objectives at their data-placed locations.

## Install

Once published: find "Butler Routes - Completionist" on the [polestar.guide](https://polestar.guide) listing, or install it through the Polestar Client.

## Development

Guides are plain-text `.guide` files at the repo root, next to `pack.json`. Publishing is via the repo's Publish to Polestar workflow: pushing a tag `vX.Y.Z` that matches `version` in `pack.json` uploads the source; the site compiles the addon. (`docs/` holds the quest contracts, authoring notes, and lint reports.)
